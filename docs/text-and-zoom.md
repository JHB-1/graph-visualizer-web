# 텍스트와 배율 조작

노드 라벨은 줄바꿈을 지원합니다. 입력한 개행을 보존하고 실제 글꼴 폭으로 추가 줄바꿈합니다. 노드 크기와 문서의 폰트 크기를 자동 변경하지 않습니다. 표시 공간이 부족하면 말줄임하고 글자를 내부 영역으로 잘라 노드 밖에 그리지 않습니다. 원문은 노드 툴팁과 속성 편집에서 확인할 수 있습니다. 이미지 출력에도 같은 줄바꿈과 잘라내기 영역을 보존합니다.

엣지 라벨은 독립 텍스트가 아니라 해당 엣지의 설명입니다. 라벨에 포인터를 올리면 연결된 선을 강조하고 툴팁에 엣지 ID와 실제 양쪽 노드를 표시합니다. 선에서 떨어진 라벨에는 가장 가까운 선까지 점선 안내선을 표시합니다. 안내선은 새 엣지나 문서 객체가 아니며 클릭/드래그 판정에도 포함하지 않습니다.

자동 라벨은 자신의 엣지 경로와 충돌 배치 결과를 따라갑니다. 수동 라벨 좌표는 월드 좌표이며 단일 노드 드래그 미리보기에서도 고정합니다. 라벨 자체를 드래그하면 수동 좌표가 저장되고, 좌표 상속을 복구하면 다시 자동 배치합니다. 별도의 자유 텍스트 주석 기능을 추가한 것은 아닙니다.

좌상단 배율은 직접 입력할 수 있습니다. 0.1%부터 800%까지 허용하며 숫자 뒤 %는 생략할 수 있습니다. Enter 또는 포커스 이탈로 반영하고 Escape는 입력을 취소합니다. 잘못된 값은 이전 유효 배율을 유지합니다. 화면 중심을 유지하며 문서, 선택, Undo를 변경하지 않습니다.

웹, 플러그인, 로컬 앱은 이 공통 렌더러를 재사용합니다. 기존에 열린 위젯은 파일 변경만으로 자동 교체되지 않으며 제품별 번들 갱신이 필요합니다.
