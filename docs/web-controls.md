# 웹 작업 공간과 코어 API

코어 커밋은 변경하지 않고 공개 API를 호출하는 웹 전용 어댑터만 확장합니다.
그래프 문서/배선/Undo를 JavaScript 사본으로 관리하지 않습니다.
일반 편집과 테마/알고리즘 변경은 동일 세션의 Scene 변경분으로 반영하며 DOM ID를 유지합니다.

| 탭 | 노출 기능 | 코어 경로 |
|---|---|---|
| 편집 | 좌표/크기/모양/라벨/부모/프로파일/선택/영역 선택 | GraphSession, ID별 graph_changes |
| 편집 | 복사/붙여넣기/복제/삭제/그룹/해제/내부 범위 | GraphSession 공개 편집/탐색 API |
| 편집 | 연결 추가/재연결/방향/반전/가중치/경유점/잠금/라벨 좌표 | GraphSession, edge_update |
| 편집 | 전체 스타일/개별 속성 상속 복구 | optional 스타일 값, resetNodeStyle/resetEdgeStyle |
| 스타일 | 노드/엣지 RGBA/폰트/굵기/크기/패딩/캔버스 전체 속성 | Defaults, CanvasStyle |
| 스타일 | 명명 노드/엣지 프로파일 | 전체 프로파일 목록 JSON, 코어 ThemeProfile 텍스트 |
| 스타일 | UTF-8 .gvtheme 입출력 | parse/serialize/theme_profile_from_document, 브라우저 파일 어댑터 |
| 스타일 | 폰트 포함/누락 정책/대체 글꼴 | FontSettings, OS 글꼴 설치/바이너리 등록 UI는 미제공 |
| 배선 | Options 전체 속성, 직선/직각/8방향/베지어 | setOptions, edge_update.routing |
| 배선 | Undo 제한, 격자 표시 | setUndoLimit, 표시 여부는 문서 밖 호스트 상태 |
| 분석 | 5종 알고리즘/단계별 강조 | runAlgorithm/setAlgorithmStep/clearAlgorithm |
| 파일 | ID별 JSON 변경분/PNG/원본 JSON | incremental_graph.update, 브라우저 출력 |
| 파일 | 전체 JSON 열기/드롭/새 문서, 미저장 확인 | 웹 전용 검증/세션 교체 어댑터, 코어 모델 변경 없음 |
| 파일 | 자동 저장/복구/끄기/기록 삭제 | 브라우저 IndexedDB, 탭별 키/Web Locks, 문서/Undo 밖 |
| 항목 | 트리/이름·ID 검색/선택/위치 찾기 | 원본 Document 조회, 기존 선택/범위 API |
| 항목 | 화면 이전/다음/선택 맞춤/북마크 | 호스트 카메라/탐색 상태, 문서/Undo 밖 |
| 편집 | 연결 핸들/엣지 끝점/경유점/라벨 직접 조작 | addEdge/reconnectEdge/setEdgeWaypoints/setEdgeLabelPosition |
| 편집 | 그룹 이동/단축키/핀치 | moveNode/기존 명령, 핀치는 호스트 카메라 |
| 분석 | 경로 실패/탐색 한도/라벨 겹침 목록과 위치 찾기 | 현재 Scene의 routing_failures/label_overlaps |
| 파일 | SVG/PNG 배율/투명/출력 범위 | 현재 Scene의 브라우저 이미지 어댑터 |

속성 폼의 상속 체크는 optional 해제이며 `0`, `false`, 알파 `0`과 구분합니다.
명명 프로파일은 기본값 위에 적용되고 개별 스타일이 그 위에 적용됩니다.
기본 크기 변경은 새 노드에 적용되며 기존 문서의 실제 크기를 일괄 덮어쓰지 않습니다.
테마 설정은 하나의 beginEdit/endEdit으로 묶어 Undo 한 번으로 복구합니다.
선택/탐색/카메라/분석 강조는 문서 이력과 분리합니다.

`ThemeProfile`이라는 API 이름은 개별 설정값 묶음의 입출력 계약입니다. 코어에는 다크/라이트
모드가 없으므로 웹이 정의한 다크/라이트/코어 기본 프리셋은 제공하지 않습니다.
화면 아래 `UI 밝기`는 렌더러 CSS만 변경하며 그래프 문서/Scene 스타일/Undo/revision/내보내기 값을 변경하지 않습니다.

스타일 입력은 `input` 이벤트에서 바로 전달합니다. 요청 처리 중에는 마지막 입력만 대기시키고
입력 칸을 다시 만들지 않아 포커스/선택 범위/색상 선택기를 유지합니다. 기본 스타일, 개별 스타일,
문서 폰트, 명명 프로파일 JSON과 ThemeProfile 텍스트에 동일하게 적용합니다.
빈 숫자/작성 중 JSON/유효하지 않은 스타일은 마지막 유효 값을 유지하고 입력 종료 시 오류를 알립니다.
웹 어댑터가 같은 입력의 연속 조절을 코어 beginEdit/endEdit으로 묶고, 포커스 이탈/다른 편집 전에
완료해 Undo 한 번으로 복구합니다. 코어 소스와 문서 형식은 변경하지 않습니다.
파일 출력은 대기 입력을 먼저 완료하고 최신 Scene/문서로 출력합니다.
스타일과 분리한 기하/연결 속성, JSON 데이터 배치 같은 명시적 작업은 기존 적용 버튼을 유지합니다.

코어의 플랫폼 계약 전부가 브라우저 기능인 것은 아닙니다. TCP/파일 시스템 어댑터는 빌드 OFF이고,
소켓 수집/OS 프로세스/OS 폰트 설치/사용자 정의 C++ Router 교체는 이 정적 웹 UI에서 제공하지 않습니다.
화면 이력/북마크는 호스트 카메라 데이터이며 C++ Navigation 인스턴스를 JSON 사본으로 만들지 않습니다.
이미지 출력은 현재 범위의 가시 Scene만 사용하며 숨김 항목은 위치 찾기 후 출력합니다.
JSON 출력은 화면 투영이 아닌 전체 원본 문서입니다. 전체 문서 열기만 새 세션으로 교체하며
그 이후 일반 편집은 기존 ID별 증분 경로를 사용합니다. [파일 계약](graph-file.md)을 참고하세요.
직접 조작은 로컬 미리보기 후 코어 명령 한 건으로 반영하고 취소/입력 오류 시 Undo를 추가하지 않습니다.
축약 대표의 끝점 후보가 여러 개면 실제 내부 ID를 선택하게 하며 대표 ID를 임의 저장하지 않습니다.
키보드 이동은 코어 스냅/그룹/간격 제약을 따릅니다. 핀치/두 손가락 이동은 카메라만 변경합니다.
임의의 C++ 라우터/포트 데이터 UI/고급 자동 배치/실시간 외부 전송은 추가하지 않았습니다.
