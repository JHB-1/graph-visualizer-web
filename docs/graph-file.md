# Graph Visualizer JSON 파일 v1

확장자는 `.json`, UTF-8 텍스트다. 전체 문서 파일은 ID별 증분 JSON 배치와 다른 형식이다.
파일 열기/드롭/복구의 최대 크기는 1 MiB이며 렌더러·전송 계층에서 검사한다.
공개 C++ 코어는 JSON이나 파일 시스템에 의존하지 않는다.

## 최상위

| 필드 | 값 |
|---|---|
| format | 문자열 `graph-visualizer` |
| version | 정수 `1` |
| document | 아래 원본 문서 객체 |
| followHostTheme | 선택적 호스트 표시 힌트, 웹은 문서 색상을 사용하며 이 값으로 기본값을 덮지 않음 |

## document

필수 필드는 `nodes`, `edges`, `defaults`, `options`, `canvas`, `fonts`다.
이 객체의 알 수 없는 필드는 거절한다. 숫자는 유한 값이어야 하며 크기/여백/열거값은 코어 검증을 통과해야 한다.

- `nodes`: 원본 노드 배열. `id`, `label`, `center`, `size`, `parent`, `subgraph`, `expanded`, `style` 필수
- 노드 선택 필드: `shape`, `profile`. 기본값/프로파일을 상속하면 `null`
- `edges`: 원본 엣지 배열. `id`, `source`, `target`, `direction`, `style` 필수
- 엣지 선택 필드: `routing`, `label`, `weight`, `waypoints`, `pathLocked`, `profile`, `labelPosition`
- `defaults`: 노드/엣지 기본 스타일, 기본 크기, 그룹 여백, 명명 노드/엣지 프로파일
- `options`: 배선/회피/격자/평행 연결 등 코어 옵션
- `canvas`: 배경/격자/선택/강조/연결 대상/핸들의 RGBA 값
- `fonts`: `embed` bool, `missing` 정수 0/1/2(Ask/Substitute/Reject), `fallbackFamily` 문자열, `assets` 배열
- 폰트 asset: `family`, `style` 문자열과 `data`(짝수 길이 16진수 바이트 문자열)

스타일/기하 세부 키는 웹 속성 폼과 같은 이름이며 알 수 없는 키는 어댑터에서 거절한다.
내보내기는 선택 필드도 정규화된 값 또는 `null`로 출력한다.
파일 열기는 폰트 자산 바이트를 보존하지만 임의의 폰트 설치/등록을 수행하지 않는다.

## ID와 상속

모든 노드/엣지 ID와 참조는 `0`부터 `18446744073709551615`까지의 **10진수 문자열**이다.
0 이외에는 선행 0을 허용하지 않는다. JavaScript number로 바꾸지 않는다.
노드와 엣지는 별도 ID 공간이므로 각각 `0`을 사용할 수 있다.
중복 ID/없는 끝점/부모 순환/없는 프로파일 등의 오류는 원본 문서 검증에서 거절한다.

`null`은 상속/미지정이다. `false`, `0`, RGBA의 `a: 0`은 명시적 값이므로 생략하지 않는다.
스타일은 기본값 → 지정 프로파일 → 개별 override 순서다.
그룹이 접혀 있어도 원래 `source`/`target`과 부모 계층을 저장한다.
화면 투영 끝점, 선택, 호버, 활동 펄스, 카메라, 탐색 이력, 북마크, Undo 스택은 문서에 저장하지 않는다.

## 교체와 실패

1. 파일 크기/JSON/버전 검사
2. 웹 어댑터에서 원본 문서와 코어 불변 조건 검증
3. 미저장 변경 확인, 사용자가 취소하면 현재 문서 유지
4. 새 코어 세션/초기 Scene 준비 후 원자적으로 교체

교체 시 선택/Undo/분석/세션 북마크를 초기화한다. 정상적인 변경분 편집과 달리 전체 문서 열기는 새 세션이다.
웹 렌더 revision은 전송 계층에서 연속성을 유지한다. 이후 편집은 기존 증분 경로를 계속 사용한다.
구문/의미/크기 검사에 실패하면 현재 문서와 이름을 유지하며 오류를 표시한다.

## 자동 복구

파일 내용과 문서 이름/미저장 상태/저장 시각을 브라우저 IndexedDB의 별도 레코드에 저장한다.
복구 레코드 버전은 `1`이며 문서 파일의 버전과 별개다. 외부 서버로 전송하지 않는다.
브라우저가 저장소를 지우거나 용량/권한을 거절할 수 있으므로 파일 다운로드의 대체 보관 수단은 아니다.
